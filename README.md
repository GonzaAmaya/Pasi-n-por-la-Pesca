# Pasión por la Pesca

Landing page para una pyme familiar dedicada a organizar viajes de pesca
de fin de semana en distintos destinos de Argentina.

## 🎣 Demo

[Ver sitio en vivo](link-si-lo-deployaste)

## Tecnologías

- React
- Vite
- CSS puro (sin frameworks)

## Funcionalidades

- Navbar responsive
- Sección de presentación con datos destacados
- Carrusel animado de sponsors (CSS puro, sin librerías)
- Sección de viajes con datos cargados desde JSON
- Integración de Google Maps embebido por destino
